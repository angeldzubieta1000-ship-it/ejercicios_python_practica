# Ejercicios Intermedios en Python — Colecciones

Este documento contiene 20 ejercicios intermedios sobre el uso de las colecciones principales en Python: **listas (incluyendo matrices)**, **tuplas**, **sets** y **diccionarios**.  
Cada ejercicio incluye su enunciado, explicación y lo que se espera como entrada y salida.

---

## 1. LISTAS Y MATRICES

### Ejercicio 1: Números mayores que el promedio
**Enunciado:**  
Solicitar al usuario una lista de números y mostrar cuáles son mayores que el promedio de la lista.

**Explicación:**  
El promedio se obtiene sumando los elementos y dividiendo por su cantidad. Luego se filtran los que sean mayores al promedio.

**Entrada esperada:**  
```
10 5 8 3 9
```

**Salida esperada:**  
```
Promedio: 7.0
Mayores que el promedio: [8, 9, 10]
```

---

### Ejercicio 2: Producto escalar de dos listas
**Enunciado:**  
Dadas dos listas del mismo tamaño con números, calcular su **producto escalar**.

**Explicación:**  
Se multiplica cada elemento en la misma posición y se suman los resultados.

**Entrada esperada:**  
```
Lista A: 1 2 3
Lista B: 4 5 6
```

**Salida esperada:**  
```
Producto escalar = 32
```

---

### Ejercicio 3: Matriz identidad
**Enunciado:**  
Solicitar un número `n` y construir una **matriz identidad** de tamaño `n×n`.

**Explicación:**  
Una matriz identidad tiene 1s en la diagonal principal y 0s en las demás posiciones.

**Entrada esperada:**  
```
n = 3
```

**Salida esperada:**  
```
[1, 0, 0]
[0, 1, 0]
[0, 0, 1]
```

---

### Ejercicio 4: Suma de dos matrices
**Enunciado:**  
Dadas dos matrices del mismo tamaño, calcular su suma elemento a elemento.

**Explicación:**  
Cada posición (i, j) se suma entre las dos matrices.

**Entrada esperada:**  
```
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
```

**Salida esperada:**  
```
[[6, 8], [10, 12]]
```

---

### Ejercicio 5: Transposición de una matriz
**Enunciado:**  
Generar la **matriz transpuesta** de una matriz ingresada por el usuario.

**Explicación:**  
Se intercambian filas por columnas: `A[i][j] → A[j][i]`.

**Entrada esperada:**  
```
[[1, 2, 3], [4, 5, 6]]
```

**Salida esperada:**  
```
[[1, 4], [2, 5], [3, 6]]
```

---

## 2. TUPLAS

### Ejercicio 1: Conversión de lista a tupla sin duplicados
**Enunciado:**  
Solicitar una lista de elementos y convertirla en una tupla sin elementos repetidos.

**Explicación:**  
Convertir la lista a set elimina duplicados; luego se convierte a tupla.

**Entrada esperada:**  
```
['rojo', 'azul', 'rojo', 'verde']
```

**Salida esperada:**  
```
('rojo', 'azul', 'verde')
```

---

### Ejercicio 2: Coordenadas dentro de un rango
**Enunciado:**  
Dadas coordenadas `(x, y)` en una tupla, verificar si están dentro de un rango dado.

**Explicación:**  
Se verifica si `x` y `y` están entre los límites.

**Entrada esperada:**  
```
Coordenada: (4, 6)
Rango: 0 a 10
```

**Salida esperada:**  
```
Dentro del rango
```

---

### Ejercicio 3: Empaquetar y desempaquetar datos
**Enunciado:**  
Dado un conjunto de datos (nombre, edad, país) empaquetados en una tupla, mostrar cada uno.

**Explicación:**  
El desempaquetado se realiza asignando la tupla a variables.

**Entrada esperada:**  
```
('Ana', 23, 'Colombia')
```

**Salida esperada:**  
```
Nombre: Ana
Edad: 23
País: Colombia
```

---

### Ejercicio 4: Comparación de tuplas
**Enunciado:**  
Ingresar dos tuplas numéricas y determinar cuál es mayor.

**Explicación:**  
Python compara tuplas elemento a elemento de forma lexicográfica.

**Entrada esperada:**  
```
(3, 4, 5)
(3, 4, 2)
```

**Salida esperada:**  
```
La primera tupla es mayor.
```

---

### Ejercicio 5: Suma y promedio con tuplas
**Enunciado:**  
Solicitar una tupla de números y calcular la suma y el promedio.

**Explicación:**  
Usar `sum()` y `len()` directamente sobre la tupla.

**Entrada esperada:**  
```
(10, 20, 30, 40)
```

**Salida esperada:**  
```
Suma = 100
Promedio = 25.0
```

---

## 3. SETS

### Ejercicio 1: Unión y diferencia entre conjuntos
**Enunciado:**  
Ingresar dos conjuntos y mostrar su unión y diferencia.

**Explicación:**  
Se usan los operadores `|` (unión) y `-` (diferencia).

**Entrada esperada:**  
```
A = {1, 2, 3}
B = {3, 4, 5}
```

**Salida esperada:**  
```
Unión: {1, 2, 3, 4, 5}
Diferencia: {1, 2}
```

---

### Ejercicio 2: Palabras únicas de una frase
**Enunciado:**  
Solicitar una frase y mostrar las palabras únicas.

**Explicación:**  
Se separa la frase con `split()` y se convierte en set.

**Entrada esperada:**  
```
"hola mundo hola python"
```

**Salida esperada:**  
```
{'hola', 'mundo', 'python'}
```

---

### Ejercicio 3: Intersección de números pares
**Enunciado:**  
Dadas dos listas de números, mostrar los pares comunes en ambas.

**Explicación:**  
Convertir a sets y usar `&` (intersección).

**Entrada esperada:**  
```
A = [2, 4, 6, 8]
B = [4, 5, 6, 9]
```

**Salida esperada:**  
```
{4, 6}
```

---

### Ejercicio 4: Diferencia simétrica
**Enunciado:**  
Mostrar los elementos que están en uno de los conjuntos pero no en ambos.

**Explicación:**  
Usar `^` o `symmetric_difference()`.

**Entrada esperada:**  
```
{1, 2, 3}
{3, 4, 5}
```

**Salida esperada:**  
```
{1, 2, 4, 5}
```

---

### Ejercicio 5: Subconjunto y superconjunto
**Enunciado:**  
Determinar si un conjunto A está contenido en otro conjunto B y viceversa.

**Explicación:**  
Usar `issubset()` y `issuperset()`.

**Entrada esperada:**  
```
A = {1, 2}
B = {1, 2, 3, 4}
```

**Salida esperada:**  
```
A es subconjunto de B
B es superconjunto de A
```

---

## 4. DICCIONARIOS

### Ejercicio 1: Agenda telefónica
**Enunciado:**  
Solicitar nombres y teléfonos y almacenarlos en un diccionario hasta que el usuario escriba "fin".

**Explicación:**  
Cada nombre será una clave y cada teléfono su valor.

**Entrada esperada:**  
```
Juan - 123
Ana - 456
fin
```

**Salida esperada:**  
```
{'Juan': '123', 'Ana': '456'}
```

---

### Ejercicio 2: Contador de palabras
**Enunciado:**  
Solicitar una frase y contar cuántas veces aparece cada palabra.

**Explicación:**  
Usar un diccionario donde las claves son las palabras y los valores sus frecuencias.

**Entrada esperada:**  
```
"hola mundo hola"
```

**Salida esperada:**  
```
{'hola': 2, 'mundo': 1}
```

---

### Ejercicio 3: Promedio de calificaciones
**Enunciado:**  
Ingresar nombres de estudiantes y sus notas, y calcular el promedio general.

**Explicación:**  
Almacenar pares nombre→nota y usar `sum()` y `len()` sobre `dict.values()`.

**Entrada esperada:**  
```
Ana: 4.0
Luis: 3.5
Sofía: 4.5
```

**Salida esperada:**  
```
Promedio general: 4.0
```

---

### Ejercicio 4: Diccionario invertido
**Enunciado:**  
Invertir un diccionario de clave→valor a valor→clave.

**Explicación:**  
Usar comprensión de diccionarios `{v: k for k, v in dic.items()}`.

**Entrada esperada:**  
```
{'a': 1, 'b': 2, 'c': 3}
```

**Salida esperada:**  
```
{1: 'a', 2: 'b', 3: 'c'}
```

---

### Ejercicio 5: Fusionar diccionarios
**Enunciado:**  
Combinar dos diccionarios en uno solo. Si hay claves repetidas, el segundo debe sobrescribir al primero.

**Explicación:**  
Usar el método `update()` o el operador `|` (Python 3.9+).

**Entrada esperada:**  
```
A = {'x': 1, 'y': 2}
B = {'y': 10, 'z': 3}
```

**Salida esperada:**  
```
{'x': 1, 'y': 10, 'z': 3}
```
